## Codebase Patterns
- npm workspaces: root at `app/`, workspaces are `server/` and `client/`
- tsx is hoisted to `app/node_modules/.bin/tsx`; npm workspace scripts can call `tsx` directly because npm adds the root bin to PATH
- ESLint config lives at `app/.eslintrc.json` with `@typescript-eslint` parser and plugin
- dep-cruiser config lives at `app/.dependency-cruiser.json` with `tsConfig` pointing at `server/tsconfig.json`
- Server src entry point: `app/server/src/index.ts`
- TypeScript: strict mode, commonjs modules, outDir `dist/`, rootDir `src/`
- Client: Vite 5 + React 18 + TypeScript, `moduleResolution: bundler`, `allowImportingTsExtensions: true`, `noEmit: true`
- Vite proxy: `server.proxy: { '/api': 'http://localhost:3000' }` in `vite.config.ts`
- `npm install --workspace=client` may warn "no workspace folder present" on first run if run before npm re-indexes; run plain `npm install` from `app/` root to let npm discover all workspaces then retry
